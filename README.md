 Project Title:-TailWag
 Description:- Tailwag Buddy is an AI-powered pet care chat assistant that helps pet owners get instant answers to daily questions about pet health, food, grooming, and behavior. It is designed for pet parents, first-time adopters, and animal care enthusiasts who need quick, simple, and reliable guidance through a friendly chat interface.
Feature:- 1)AI-powered pet care chat support 
2)Answers about food, grooming, behavior & basic health
3) Instant responses in simple language
4) Mobile-friendly responsive UI
5) Clean pet-themed frontend design
6) Quick question–answer interaction model
 Tech Stack:-1) React.js
2) Lovable
3)Gemini API
Installation:-
npm install
npm run dev
 Usage:-
1.Open the app in your browser.
2.type your pet-related question in the chat box.
3.Get instant AI-generated guidance.
4.Ask follow-up questions for more clarity.
5.Use it as a daily pet care helper tool.
